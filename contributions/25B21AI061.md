## Three Git Commands I Learned

1. `git add` — Stages changes before committing them.
2. `git commit` — Saves staged changes as a commit.
3. `git push` — Uploads local commits to a remote repository.

## Purpose of GitHub

GitHub hosts Git repositories online and helps developers store code, track changes, collaborate, and review contributions.

## Benefits of Using Branches

Branches allow developers to work on features or changes separately without directly affecting the main branch. Pull requests help review changes before merging them.
